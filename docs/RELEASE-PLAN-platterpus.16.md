- **A sector that will not read is still untested on a drive**, so `.15`'s
  retry fix has not been reached on hardware.
- **`track is partially accurately ripped` is unchanged**, and round 26 showed it
  said of a track whose bytes were wrong (`docs/KNOWN-ISSUES.md`). The wording
  is round 27's, with Platterpus's answer first.
- **The album loudness block still covers whatever was read.** Round 27's too.
- **At `-P 0`, one unreadable sector still hangs at any `-r`.** Platterpus never
  passes `-P`.
- **The cache figure is still wrong** by roughly fifteen times. **Do not cite
  it.**
- **C2 stays `UNREACHABLE`** on the rig's drive. `-f` and CD-TEXT from a
  physical disc are *not yet done*, which is a different claim.
